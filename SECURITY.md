## 1. Propósito del repositorio

Este repositorio contiene **37 proyectos** de inteligencia de amenazas
(CTI/OSINT), herramientas defensivas y documentación técnica, elaborados
a partir de **información pública recopilada**. Su único propósito es:

- **Educativo** — formar a analistas de seguridad y equipos SOC/Blue Team.
- **Defensivo** — permitir a organizaciones conocer las TTPs de actores
  maliciosos y protegerse.
- **Investigación** — servir como referencia para analistas de threat
  intelligence, académicos y profesionales de ciberseguridad.

**Este repositorio NO es un manual de hacking.**
**NO contiene exploits funcionales.**
**NO contiene malware operativo.**
**NO contiene instrucciones paso a paso para atacar sistemas.**
